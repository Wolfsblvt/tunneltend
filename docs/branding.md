# Branding status

## Meaning

This document records the current product identity boundary. TunnelTend and `tunneltend` are the incumbent name and slug; visual identity remains provisional until owner co-design approves the icon, SVG system, palette, and voice.

**TunnelTend** is the current product name. The command and repository slug are **`tunneltend`**.

The name expresses the product's core promise: register MCP services once, then let a small local manager tend their tunnels, health, recovery, startup, and official-client lifecycle. It is deliberately more domestic and dependable than cloud-orchestration language.

The project is unofficial and must never imply affiliation with or endorsement by OpenAI. OpenAI's official tunnel client remains an external dependency downloaded from its official release source.

No final icon, palette, or visual identity is committed yet. `assets/brand/` contains only implementation guidance until the owner co-design in `carriers/Threshold-CoDesign-Branding.md` is complete. Candidate artwork must remain visibly provisional until approved.

A future rename must update the complete identity surface, not merely README text: module and command names, package/repository slugs, state directories, Scheduled Task paths, mutex/event identifiers, schemas, documentation, release artifacts, and migration behavior. `scripts/Rename-Product.ps1` is the bounded mechanical helper; it does not make the product decision.
