# Current direction

## Meaning

This document carries TunnelTend's durable near-term direction. The first stable Windows CLI, the qualified 1.0.1 patch, and the public website and manual are live. The current outcome is to keep that public result current: carry the selected Docs Home migration and shell repair, qualify new stable official-client releases before promoting their compatibility, and preserve the product/provider boundary while Wolf Ops completes its separately owned operating follow-through. Current execution, review Returns, and exact operating obligations live in the shared workplace. The Vision and autonomous local-manager scope remain unchanged.

## Constraints

- Do not bundle the official OpenAI client.
- Preserve the default autonomous behavior, secret references, process ownership and read/plan/apply grammar.
- Preserve the no-hand-written-JSON normal journey for humans and local coding agents.
- Keep website source, build/preview, public hosting and actual consumer operation distinct.
- Keep the reader-facing manual under `website/` distinct from maintainer and product truth under `docs/`.
- Product copy, identity and manual remain in TunnelTend; provider/DNS/credential and live publication evidence remain with Wolf Ops.

## Not now

- A tray application or graphical dashboard.
- Non-Windows automation backends.
- A hosted TunnelTend service.
- Automatic source-control, package, build, migration or container update strategies.
- Package-registry publication.

## Completion boundary

The current Docs slice is complete only when the dedicated canonical host is live, the old path reaches the matching destination in one permanent redirect, canonical/discovery output names one indexable copy, the two observed shell defects are repaired, and the real responsive and keyboard journeys pass. The v0.0.18 alignment is complete only when the generated upstream coordinate is refreshed from authoritative release data and the actual Windows asset passes verified acquisition, version and capability checks, plus the updater's guarded replacement boundary. An unchanged source file or successful metadata read is supporting evidence, not binary compatibility proof. A newly connected control-plane session remains a separately named observation unless it is actually exercised. These slices do not reopen the already completed 1.0.1 release or public-Home launch.
