# TunnelTend 1.0.0

## Meaning

This is the audience account for TunnelTend's first stable Windows release. The [GitHub Release](https://github.com/Wolfsblvt/tunneltend/releases/tag/v1.0.0) carries its downloadable artifacts and publication standing; this source file alone does not establish publication.

Register an MCP service once. TunnelTend keeps its local process and official OpenAI tunnel running, remembers deliberate stops, and gives you useful facts when something needs attention.

The first release brings that routine into one Windows CLI: startup at sign-in, watchdog recovery with visible limits, optional source-change restarts, and verified official-client updates with backup and rollback. You can operate one service or a small fleet without assembling Task Scheduler entries or editing internal JSON.

## A quiet caretaker

- Register command-backed or HTTP MCP services, or explicitly adopt existing official-client aliases.
- Inspect desired state, live health and diagnosis without changing persisted state. Preview reconciliation or repairs before applying them.
- Stop a service for the current session without the watchdog immediately bringing it back. The next sign-in establishes a fresh session.
- Recover missing or unhealthy processes with ownership checks, persisted backoff and a bounded attempt budget.
- Update the separate official client only after release verification and staged compatibility checks; restore the fleet or roll back if replacement fails.

A real remote MCP echo returned **“TunnelTend remote proof — Grüße 🐺”** through ChatGPT during Windows qualification. Natural sign-in startup and sleep/resume recovery were also observed. Those connected observations used official client v0.0.16; v0.0.17 was separately acquired through the public updater, digest-verified and passed all six adapter capability probes. A connected v0.0.17 session has not been exercised.

The qualification does not establish a connected v0.0.17 session, live adoption of a pre-existing official alias, or a deliberately missed Scheduled Task trigger. The installed native task entry was observed without a console; a global no-focus observation was not captured. These are coverage limits, not claims of uninterrupted availability.

## Start with your own service

Download the ZIP and SHA-256 file from the release, verify and extract it, then follow [installation](../getting-started.md) and [service registration](../registration.md). PowerShell 7 on Windows 11 is required. Your OpenAI organization/workspace, tunnel and runtime credential remain separate prerequisites; credentials are supplied by reference, never as inline registry values.

TunnelTend is unofficial and does not implement OpenAI's tunnel protocol. The official binary is downloaded separately and is not included in this AGPL-3.0-only source distribution. Application builds, dependency updates and migrations remain under your explicit control.

The release uses the approved Fold identity and Moonpool palette. A product website follows separately; it is not needed to install or use the CLI.
