# TunnelTend 1.0.2

## Meaning

This is the draft audience account for the 1.0.2 patch candidate. It describes the prepared changes; 1.0.2 is not yet published. Downloadable availability remains with the [GitHub Releases](https://github.com/Wolfsblvt/tunneltend/releases).

TunnelTend can keep following compatible official OpenAI client releases without waiting for a matching TunnelTend release. This patch strengthens that existing automatic route: the exact stable release selected for an update is also the one downloaded, and staged checks exercise the required command shapes and credential-free JSON behavior before replacing the installed client. Verified downloads, backup and rollback remain part of the update.

## Updating an existing installation

Existing users need one TunnelTend package update to receive these adapter and updater changes. Once 1.0.2 is published, rerun the [ordinary installer](https://docs.tunneltend.com/getting-started/) against the same installation and state locations. It preserves saved automation choices, scope defaults, credential references and the official-client location unless you explicitly change them. You do not need a TunnelTend package update for every later compatible OpenAI release.

Automatic maintenance keeps the installed bytes when the official client reports the same version. If upstream changes an asset under the same version, that change remains visible for maintainer judgment; it does not silently replace your current copy. Missing or stale website evidence does not disable local verified updates.

The public compatibility view distinguishes the latest observed official release from the last routine-qualified one. It identifies the tested TunnelTend package and separates verified distribution, credential-free CLI checks, owned-fleet behavior and a connected MCP call. A source-only result does not mean the published package contains that source.

This patch also preserves installer choices during repeat installation and improves recovery from failed installation. The manual now has its own [Docs Home](https://docs.tunneltend.com/), with shared appearance preferences and repaired narrow search results.

Windows 11 and PowerShell 7.4 or newer remain required. The official OpenAI client is a separate verified download and is never bundled. Windows x64 acquisition, CLI checks and transactional update/rollback have been exercised with genuine v0.0.17 and v0.0.18 clients. ARM64 archive verification is separate from native ARM64 execution. These checks do not establish a new connected fleet or MCP-consumer session; [earlier connected qualification](1.0.0.md) remains bounded to its stated client version.
