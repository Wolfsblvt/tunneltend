# TunnelTend 1.0.1

## Meaning

This is the audience account for the diagnostic and installation fixes in the 1.0.1 patch. The [GitHub Release](https://github.com/Wolfsblvt/tunneltend/releases/tag/v1.0.1) carries downloadable availability; this source alone does not establish publication.

Plain-text diagnostics now work when there is something to report. Previously, status, health and doctor could fail with a formatting error as soon as a service or diagnostic existed; JSON output was unaffected. The online installer also preserves the ordinary installer's named switches, so unattended setup and custom installation paths reach the same supported installer correctly.

The patch includes the approved Fold wordmark and lockup, with a public website and reader-first manual prepared for tunneltend.com. Website hosting is a separate publication: use the [repository guide](../getting-started.md) until that Home is admitted. The release ZIP remains usable independently of the website.

Windows 11 and PowerShell 7.4 or newer remain required. Registered services, session intent and routine recovery behavior are unchanged. The official OpenAI client remains a separate verified download and is never bundled. The [original 1.0 qualification](1.0.0.md) describes the observed sign-in, sleep/resume and remote MCP boundaries and their limits; this patch does not claim a new connected qualification.
