# TunnelTend kickoff carriers

## Meaning

This directory contains copy-ready launch prompts for the remaining bounded TunnelTend work after the source foundation reaches `main`. Each carrier owns one distinct consequence and names its authority, evidence, and return boundary. These files are launch input, not proof that the work ran or passed.

| Carrier | Use |
| --- | --- |
| `Local-Repository-Push-And-Qualification.md` | Push the supplied exact Git carrier into the empty public repository, consume hosted CI, and perform the complete Windows qualification. |
| `Local-Windows-Qualification.md` | Prove the exact `main` candidate on a disposable Windows lifecycle, including Task Scheduler, recovery, update, rollback, and uninstall. |
| `Local-Installation-Handoff.md` | Install and configure TunnelTend on Wolf's real Windows account after qualification. |
| `Official-Client-Compatibility.md` | Review a new official `openai/tunnel-client` release against TunnelTend's adapter and update path. |
| `Recovery-Security-Review.md` | Cold hostile review of process ownership, recovery budgets, secrets, archives, update rollback, and unattended execution. |
| `Release-Integration.md` | Integrate returned evidence, build the exact release candidate, and prepare publication without silently publishing it. |
| `Threshold-CoDesign-Branding.md` | Live Wolf/Nyxara co-design for durable identity, iconography, palette, voice, and repository presentation. |

Use the smallest carrier whose consequence matches the work. Do not merge branding, Windows qualification, security review, and release publication into one heroic session that returns four half-answers and a haunted desktop.
